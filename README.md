# 嘉豪指数测试

黑白荧光绿的原创娱乐测评，围绕主角感、装酷和日常自我表达。

16 道场景题，四个维度：出场排面、高光表达、故事浓度、高手姿态。完成后得到 0 至 100 的指数、风格称号、实际选择回放及可下载的 1080 × 1560 PNG。

## 本地打开

直接双击 `index.html` 即可，无需安装依赖。也可在本目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

打开 http://127.0.0.1:8765/ 。本机预览地址不对其他设备开放。

## 检查与构建

需要 Node.js 20 或更高版本，无第三方包。

```sh
npm test
npm run build
```

`dist/` 只包含显式列出的六个运行文件。GitHub Actions 检查规则并构建后，将 `dist/` 发布到 GitHub Pages。使用相对资源路径与 hash 状态，兼容仓库子路径托管。此项目已由用户审核并授权公开源码与网站。

## 计分

每题四个选择，分别计 0、1、2、3 分，选项顺序打散。每维四题，满分 12；总满分 48。总指数为 `round(总分 / 48 × 100)`，维度值按 `round(维度分 / 12 × 100)` 计算。

指数低于 20 为原生松弛派；达到 80 为全域嘉豪；其余按最高维度生成氛围导演豪、高光发言豪、故事男主豪或技术流嘉豪。并列时按维度声明顺序判定。所有称号均是娱乐叙事；“男主”是剧情称号，不限制参与者性别。

## 数据与保存

不收集姓名、联系方式，无后端、埋点、外部字体或远程依赖。答案和进度存于当前浏览器的 `jiahao-index-v1` 本地存储键中，重测确认后替换；浏览器禁止存储时仍能完成当次答题。结果图片在本地 canvas 生成，手机无法直接下载时可打开图片长按保存。Chrome 模拟手机尺寸已验收；真实 iOS/Android 浏览器仍应在公开部署后验收。

## 文件

- `quiz-data.js`：题目、四维分值、六种结果文案与确定性评分。
- `app.js`：答题、返回修改、恢复进度、重测和真实图片下载。
- `styles.css`、`tokens.css`、`base.css`：Hallmark Sticker vinyl 设计。
- `scripts/check.mjs`：计分边界、六种类型、证据引用和修改答案的重算检查。
- `scripts/build.mjs`：明确的静态资源清单，不发布源码说明、检查记录或审核图片。

结果不是科学量表、人群排名或心理诊断。本站没有付费校验、兑换码、自动发货或购买解锁功能。
